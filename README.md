#  Minecraft City with secrets Builder Mod
Этот мод написан на Python и позволяет в один клик сгенерировать целый городской квартал в Minecraft! Проект создан в рамках образовательного курса по программированию.

## Возможности 

* **Процедурная генерация:** Город строится по заранее заданному массиву (карте) 7х7.
* **Умные здания:** Дома имеют несколько этажей, окна, лестницы с люками и автоматические двери, которые всегда выходят на улицу.
* **Парки и зоны отдыха:** В городе есть парки с каруселями, фонтанами, лавочками и клумбами.
* **Движение:** По главной магистрали (Highway) ездят две машины в противоположных направлениях.
* **Секрет:** В одном из случайно выбранных домов на случайном этаже спрятан сундук с сокровищами!
* **Ориентация по игроку:** Город всегда строится ровно перед игроком, куда бы он ни смотрел.

## Требования

Для запуска мода вам понадобится:
1. Установленный **Python** (версия 3.8 или выше).
2. Библиотека **mcpi**. Установить её можно через командную строку:
   ```bash
   pip install mcpi
3. Запущенный Minecraft Java Edition (версия 1.8 – 1.12.2).

 Как запустить
Скачайте файл с кодом мода (например, city_mod.py).

Запустите Minecraft и зайдите в свой мир.
Обязательно! Нажмите Esc -> «Открыть для сети» (Open to LAN) -> нажмите «Запустить мир».
Запустите скрипт city_mod.py через PyCharm или командную строку.
В игре в чате появится приветствие. Введите команду city.

 Команды
Команда в чат	Действие
city	Сгенерировать город перед игроком
secret	Спрятать сундук с сокровищами в случайном доме (выведет координаты в чат)
clear Очистить пространство вокруг игрока в радиусе 200х200х200 блоков
 Решение проблем
Ошибка RequestError: Вы забыли открыть мир для сети (Open to LAN) или запустили скрипт до того, как зашли в игру. Зайдите в мир, откройте его для сети и перезапустите скрипт.

Машины моргают: Это ограничение библиотеки mcpi.
